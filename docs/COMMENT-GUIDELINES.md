# 주석 작성 가이드라인

**간결하게 핵심만.** 코드를 읽으면 아는 것은 적지 않는다. 적을 것은 코드에 안 드러나는 것 -
왜 이 호출이 여기 있는지, 왜 이 순서인지다.

**설명이 필요한 코드는 구현이 확정된 뒤에 적는다.** 값을 만지는 중에 붙인 주석은 다음 수정에서
곧 낡는다.

**설명 뒤에 짧은 예시를 붙인다.** 형태/순서/변환처럼 예시 한 줄로 보일 수 있으면 설명을 길게
잇는 대신 그것으로 마친다. 예시로 담기 어려운 것(이유, 제약)은 설명으로 둔다.

| O | X |
|---|---|
| `// 중간을 빼면 뒤 인덱스가 당겨진다. [a, b, c] -> removeAt(1) -> [a, c]` | `// 중간 요소를 빼면 그 뒤 요소들의 인덱스가 하나씩 앞으로 당겨지고, 목록의 길이도 그만큼 줄어든다` |
| `// 필드 순서대로 값만 편다. { a: 1, b: 2 } -> [1, 2]` | `// 객체의 필드를 선언 순서대로 훑어 값만 배열로 뽑아낸다` |
| `// 마디로 자른다. "a.b.c" -> ["a", "b", "c"]` | `// 점으로 구분된 경로 문자열을 마디 단위로 잘라 배열로 만든다` |

**예시가 이미 말한 것은 설명으로 되풀이하지 않는다.** 앞줄을 빼도 뜻이 같으면 뺀다.

| O | X |
|---|---|
| `// "a.b.c" -> ["a", "b", "c"]` | `// 마디로 자른다. "a.b.c" -> ["a", "b", "c"]` |
| `// { a: 1, b: 2 } -> [1, 2]` | `// 필드 순서대로 값만 편다. { a: 1, b: 2 } -> [1, 2]` |

**주석만 읽고 알 수 있게 쓴다.** 코드를 읽는 사람에게는 이 코드를 만들며 나눈 대화가 없다.
대화에서 정한 낱말(순번, 가지)이나 대화에서 쓴 예시의 줄임을 그대로 옮기면 읽는 쪽은 뜻을
모른다. 짧게 쓰는 것보다 알아듣게 쓰는 것이 먼저다.

- 낱말은 무엇의 무엇인지 적는다 - `순번`이 아니라 `식 바이트 안의 위치`.
- 예시에는 전제를 붙인다 - 식을 어떻게 펴는지, 칸 번호가 무엇인지 적고 나서 결과를 적는다.
- 예시의 각 단계는 무엇이 무엇을 해서 어떻게 되는지 문장으로 적는다. 화살표로 이어 붙이지 않는다.
- 결과에 눈에 띄는 점이 있으면 그 까닭을 적는다 - `a는 두 번 나온다`가 아니라 `a는 위치 0과 7
  두 곳에서 읽는다`.

| O | X |
|---|---|
| `// positions  readLeaves[k]의 칸을 읽는 명령이 식 바이트 어디에 있는지. 같은 변수가 식에`<br>`//             여러 번 쓰이면 위치도 여럿이다.`<br>`// (a + b) * (a - c)   a, b, c의 leafIndex가 각각 10, 11, 12라면`<br>`//   위치  0 LOAD_VAR a, 3 LOAD_VAR b, 6 ADD, 7 LOAD_VAR a, 10 LOAD_VAR c, 13 SUB, 14 MUL`<br>`//   positions [[0, 7], [3], [10]]   a는 위치 0과 7 두 곳에서 읽는다` | `// (a + b) * (a - c) -> positions [[0, 7], [3], [10]]  a는 두 번 나온다` |
| `// (a + b) * (c - d)에서 c가 바뀌면 changed = [7] (LOAD_VAR c의 위치)`<br>`//   a + b  위치 0~6  7을 안 품는다 -> 계산하지 않고 cache의 지난번 값을 쓴다` | `// changed [7] -> 0에서 ADD의 cache를 올리고 7로` |

**같은 타입이 나란히 오면 예시로 인자 순서를 못 박는다.** 타입만 봐서는 어느 자리가 무엇인지
알 수 없다 - 코드를 읽으면 아는 것이 아니다.

O - 예시가 첫 자리는 배열, 둘째 자리는 인덱스임을 못 박는다.

```rust
/// a[i + 1] -> Index(a, i + 1)
Index(Box<Expr>, Box<Expr>, NodeRange),
```

X - 설명만으로는 둘 중 어느 자리가 배열이고 어느 자리가 인덱스인지 알 수 없다.

```rust
/// 왼쪽 배열 식의 i번째 요소
Index(Box<Expr>, Box<Expr>, NodeRange),
```
