식 갱신 비교 - quble / React / Svelte

주문 목록 N행을 그리고, 행마다 식 넷을 둔다. 대상 이름을 누르면 새 탭에 그 대상만 뜬다. 그 탭에서 측정을 누르면 결과가 이 표에 바로 들어온다. 크기와 압축을 바꾸면 대상 탭도 그 설정으로 열린다. 

금액  (row.price * row.qty - row.discount) * (100 + tax) / 100 * rate
재고  row.stock - row.qty
비교  row.price - rows[pivot].price
경고  row.qty > 0 && row.stock - row.qty < 5 && row.price * row.qty > threshold

  • 행 +1 - 행 하나의 수량만 바뀐다. React(memo 없음)는 모든 행을 다시 렌더한다.
  • 환율 변경 - 모든 행 금액이 바뀐다. quble은 (price * qty - discount) * (100 + tax) / 100을 건너뛴다.
  • 기준 변경 - 모든 행 경고 식을 다시 세지만 값은 거의 그대로라 DOM에는 거의 안 쓴다.
  • 기준 행 이동 - 모든 행 비교 식이 다른 행의 가격을 읽게 된다. quble은 식마다 가격 leaf 구독을 새 기준 행으로 다시 건다.
  • 기준 행 가격 변경 - 한 행의 가격만 바뀌지만 모든 행 비교 식이 다시 센다. quble은 그 가격 leaf의 구독 함수 N개가 호출된다.
  • 압축을 바꾼 뒤에는 대상 탭을 새로 열어야 그 압축으로 받는다. 캐시는 꺼 두었다.
